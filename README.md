# Resume-Pipeline
Transforms your experience into a beautiful resume

## GOAL

- One Mega Data thread of your Work history, personal info, education + user definable extensions
- Parse job for key words, skills, tools(distinguish between required and preferred)
- Ask the user questions to create to find more skill that might have been missed
- Make a Final resume using a given typst template (The ai must be able to understand typst, fit everything on one page, and FOLLOW THE TEMPLATE EXECTLY)
